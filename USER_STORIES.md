## Level 3 - Task 01: User Stories 

Definition: User Story Eine User Story ist eine kurze Beschreibung einer gewünschten Software-Funktion aus der
Perspektive des Endanwenders. Die Standard-Formel: Als [Rolle] möchte ich [Funktion/Ziel] , damit [Nutzen/Grund] 

## US1: Beispiel
Beispiel:Als Archivar im Amt möchte ich bei einer Akte sofort maschinenverarbeitbar sehen, um welchen
Dokumententyp es sich handelt, damit ich nicht jede Datei einzeln öffnen muss und ggf. Erhaltungsmaßnahmen
ergreifen kann.


## US2: Perspektive A: Fristen & Controlling
BSP: Als Archivarin möchte ich jedem Dokument ein Aufbewahrungsdatum zuweisen können, damit ich Löschfristen einhalte und das System mich informiert, wenn Dateien gelöscht werden müssen.

## US3: Perspektive B: Sicherheit & Datenschutz (DSGVO)
BPS: Als Datenschutzbeauftragte möchte ich jedes Dokument mit einer Vertraulichkeitsstufe (z. B. öffentlich oder intern) markieren, damit sichergestellt ist, dass nur berechtigte Personen Zugriff auf sensible Daten haben.
